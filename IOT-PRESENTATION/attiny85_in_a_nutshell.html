1. Introduction and learning objectives

The ATtiny85 is a small, low-power, 8-bit microcontroller from Microchip's AVR family. It combines a CPU, program memory, data memory, timers, digital I/O, and communication/peripheral hardware in one integrated circuit. It is useful when a project needs simple control but does not need a large microcontroller.

What you will learn

  • Identify its memories and core peripherals.
  • Read the 8-pin DIP pinout.
  • Explain reset, clock, GPIO and timers.
  • Write a basic embedded C program.

Prerequisites

  • Binary and hexadecimal numbers
  • Digital logic and voltage levels
  • Basic C: variables, loops, functions
  • Ohm's law and circuit safety

Important terms

  • MCU: CPU + memory + peripherals
  • GPIO: configurable digital pin
  • Flash: non-volatile program memory
  • PWM: pulse-width modulation
  • ISP: in-system programming
In one line: a microcontroller reads inputs, executes a stored program, and controls outputs using its pins and peripherals.

Why it matters

Learning ATtiny85 introduces core embedded concepts—register-level I/O, timers, interrupts, ADC, serial communication and power-aware design—without the complexity of a large system. The same ideas transfer to larger AVR, ARM and other MCU families.

4. How it works: from power-up to output

  1. Power and reset: provide a regulated supply within the datasheet range and a common ground. Reset places the MCU into a known startup state.
  2. Clock: an internal oscillator or a configured external clock sets the instruction timing. Fuses determine important clock/reset settings.
  3. Fetch and execute: the CPU fetches instructions from Flash, decodes them and operates on registers/data.
  4. Read inputs: configure a pin as input and read its logic level or use an ADC channel for analog voltage.
  5. Process: the program makes decisions, updates variables and can respond to interrupts.
  6. Control outputs: set GPIO levels, generate PWM, or communicate using a peripheral.

Digital I/O basics

DDRB bit = 1 → output; DDRB bit = 0 → input
PORTB bit = 1 on input → enable internal pull-up (where supported)
PINB → read the digital input pin state

AVR GPIO registers are bit-oriented. Use bit masks such as (1 << PB0) so code changes only the intended pin.

DC and time-varying behaviour

DC: the supply powers the CPU and peripherals; a GPIO output is driven HIGH or LOW according to its configuration and load. The pin is not a general-purpose power supply—use a transistor/MOSFET driver for loads requiring more current.

Time-varying: timers count clock ticks and can create periodic interrupts or PWM. ADC samples analog input voltage and converts it to a digital number. USI shifts bits for supported serial protocols.

Clock and timing

Timer tick period = prescaler / fCPU

For a timer with prescaler \(N\), clock frequency \(f_{CPU}\), and an \(n\)-bit counter, the overflow interval is \(T_{ov}=2^nN/f_{CPU}\), assuming the counter starts at zero and counts continuously to overflow. Real timing also depends on clock tolerance and software overhead.

ADC idea

Ideal ADC code ≈ Vin / Vref × (210 − 1)

For a 10-bit ADC, codes range from 0 to 1023. This approximation assumes the input is within the allowed ADC range and uses the selected reference. Reference choice, noise and quantization affect accuracy.

5. Programming example: blink an LED

This example uses AVR-GCC style C and assumes an LED with a current-limiting resistor is connected to PB0 (physical pin 5) and ground. The exact delay depends on the configured CPU clock and compiler settings.

#define F_CPU 1000000UL
#include <avr/io.h>
#include <util/delay.h>

int main(void) {
    DDRB |= (1 << PB0);       // PB0 as output
    while (1) {
        PORTB ^= (1 << PB0);  // toggle output
        _delay_ms(500);
    }
}

What each line does

CodeMeaning
#define F_CPU 1000000ULDeclares the clock assumed by delay routines; it must match the actual clock configuration.
DDRB |= (1 << PB0)Sets PB0's data-direction bit to output without changing other bits.
PORTB ^= (1 << PB0)Toggles PB0 using XOR.
_delay_ms(500)Waits approximately half a second under the correct clock/compiler setup.
Do not connect an LED directly without a resistor. Estimate resistor value using \(R=(V_{CC}-V_F)/I_{LED}\), then verify the MCU pin current and total port/package limits in the datasheet. For motors, relays or high-current LEDs, use a driver stage.

6. Solved examples

Easy

Example 1 — ADC resolution

Question: A 10-bit ADC uses a 5.0 V reference. Estimate the voltage represented by one LSB.

Formula: LSB ≈ \(V_{ref}/2^{10}\).

Substitution: \(5.0/1024 = 0.004883\) V.

Answer: approximately 4.88 mV per LSB. A code change of one count represents a small voltage step; actual conversion error also includes offset, gain, noise and reference errors.

Moderate

Example 2 — Timer overflow

Question: For an 8-bit timer at 1 MHz with prescaler 64, find the overflow interval from zero.

Formula: \(T=256N/f_{CPU}\).

Substitution: \(T=256×64/1,000,000=0.016384\) s.

Answer: 16.384 ms, before accounting for interrupt/service software overhead. The prescaler slows the timer relative to the CPU clock.

GATE-style

Example 3 — GPIO bit masking

Question: DDRB is initially 00000000. Set PB0 and PB3 as outputs without affecting other bits. What is the result?

Formula: DDRB |= (1<<PB0) | (1<<PB3).

Calculation: bit 0 mask = 00000001; bit 3 mask = 00001000; OR gives 00001001.

Answer: 00001001 (decimal 9). Bit masks preserve all unrelated register bits.

7. Applications and industry relevance

Small controllers

Button interfaces, LED patterns, simple alarms, toys and low-complexity control logic.

Sensor nodes

Read a sensor through the ADC and trigger an output or send a compact result over a supported serial interface.

Power-aware devices

Battery-operated gadgets can use sleep modes and wake-up events to reduce average energy use.

Practical engineering considerations

  • Power: verify voltage, current, brown-out settings and decoupling capacitor placement.
  • Clock: internal RC clocks are convenient but less accurate than a suitable calibrated/external source.
  • Memory: 512 bytes of SRAM is small; avoid large buffers and deep call stacks.
  • Programming: commonly programmed through ISP using a compatible programmer; fuse settings can affect reset and clock access.
  • EMC/reliability: use good grounding, short wiring, pull-ups where appropriate and filtering for noisy inputs.
  • Lifecycle: confirm current availability, package options and recommended migration path before starting a new commercial design.

Roles connected to these skills: embedded firmware, electronics prototyping, hardware validation, test engineering, low-power design and product R&D.

8. GATE-style practice (10 questions)

These are original practice questions, not claimed previous-year GATE questions. Open each question to view the answer and explanation.

Q1 · Easy — What is the ATtiny85?

Answer: B. An 8-bit AVR microcontroller. It integrates CPU, memory and peripherals on one chip; it is not simply a processor or a memory IC.

A) Op-amp · B) 8-bit microcontroller · C) FPGA · D) DRAM chip

Q2 · Easy — Which memory stores the program without power?

Answer: A — Flash. Flash is non-volatile program memory. SRAM is volatile working memory.

A) Flash · B) SRAM · C) CPU register only · D) Timer counter

Q3 · Easy — How many bits does its ADC produce?

Answer: C — 10 bits. A 10-bit conversion has 2¹⁰ = 1024 possible codes (0–1023).

A) 4 · B) 8 · C) 10 · D) 16

Q4 · Moderate — If DDRB bit 2 is 1, PB2 is configured as…

Answer: B — output. In AVR data-direction registers, a 1 selects output and a 0 selects input.

A) Analog-only · B) Output · C) Always high impedance regardless of state · D) Reset

Q5 · Moderate — A 10-bit ADC has how many output codes?

Answer: D — 1024. The number of distinct codes is 2ⁿ, while the maximum code is 2ⁿ−1 = 1023.

A) 10 · B) 100 · C) 1023 · D) 1024

Q6 · Moderate — What is the ideal LSB for Vref = 2.56 V and 10-bit ADC using Vref/1024?

Answer: A — 2.5 mV. 2.56/1024 = 0.0025 V.

A) 2.5 mV · B) 25 mV · C) 0.25 V · D) 1 mV

Q7 · Moderate — Why use a current-limiting resistor with an LED?

Answer: C. It limits current to protect the LED and MCU pin. GPIO pins cannot be treated as ideal voltage sources with unlimited current.

A) Increase Flash · B) Set clock fuse · C) Limit current · D) Improve ADC resolution

Q8 · Difficult — An 8-bit timer runs at 2 MHz with prescaler 8. Overflow interval from zero is…

Answer: B — 1.024 ms. \(256×8/2,000,000=0.001024\) s.

A) 0.128 ms · B) 1.024 ms · C) 8.192 ms · D) 10.24 ms

Q9 · Difficult — What is a key consequence of disabling RESET to use PB5 as GPIO?

Answer: A. Standard reset-based ISP access can be lost or made more complicated; fuse changes require careful planning and recovery capability.

A) Programming/recovery implications · B) SRAM becomes non-volatile · C) ADC becomes 12-bit · D) CPU becomes 16-bit

Q10 · Difficult — Why might a delay loop run at the wrong speed?

Answer: D. The compile-time F_CPU definition and actual clock/fuse configuration may not match, and software/compiler overhead also matters.

A) Flash is non-volatile · B) GPIO has direction · C) ADC has reference · D) Clock assumptions are incorrect

9. Core electronics interview questions

1. What is a microcontroller, and how is it different from a microprocessor?

A microcontroller integrates CPU, memory and peripherals for embedded control. A microprocessor typically relies more on external memory/peripherals and is often used for more general-purpose computing.

2. Explain Flash, SRAM and EEPROM.

Flash stores program code; SRAM stores temporary variables and stack while powered; EEPROM stores small amounts of data across power cycles. EEPROM writes have endurance and timing limits.

3. What is the difference between DDRB, PORTB and PINB?

DDRB selects input/output direction, PORTB writes output levels or enables pull-ups on inputs, and PINB reads pin states.

4. How would you interface an LED?

Configure a GPIO as output, add a series resistor, observe polarity and verify pin/package current limits. Use a transistor driver for larger loads.

5. What does a timer prescaler do?

It divides the clock feeding a timer, increasing the time between timer increments and enabling longer intervals or lower-frequency waveforms.

6. Explain PWM and one application.

PWM varies the duty cycle of a digital waveform. After suitable filtering or in a switching load, the average delivered power/voltage can be controlled. Applications include LED dimming and motor control with a driver.

7. How does a 10-bit ADC represent a voltage?

It maps an allowed analog range to 1024 codes. Ideal code is approximately Vin/Vref × 1023 (or use the LSB convention Vref/1024); check the datasheet's transfer convention and input limits.

8. An MCU does not run after changing fuses. What do you check?

Check supply, reset wiring, selected clock source, fuse settings, programmer connection and clock availability. A wrong clock fuse may require supplying the expected clock to recover programming access.

9. Why can a button input flicker between 0 and 1?

Mechanical contact bounce and floating inputs are common causes. Use a pull-up/down, debounce in software or hardware, and define a stable active level.

10. What would you measure in a lab when a timer output is incorrect?

Verify actual clock frequency, fuse/clock configuration, timer prescaler and compare/overflow settings. Probe the output with an oscilloscope or logic analyzer and compare measured period and duty cycle to calculations.

11. What is ISP?

In-system programming updates device Flash while the chip is installed in the target circuit, using programming pins and a compatible programmer.

12. How would you reduce battery consumption?

Use sleep modes, wake on necessary events, reduce clock frequency when suitable, disable unused peripherals, avoid unnecessary LED current and check leakage paths.

Advantages and limitations

Advantages

  • Small package and low component count
  • Integrated timer, ADC and GPIO
  • Low-power modes
  • Good for learning register-level embedded design

Limitations

  • Very limited SRAM and Flash compared with modern MCUs
  • Few pins and limited peripheral concurrency
  • 8-bit processing and modest performance
  • Clock accuracy and pin current must be considered

Common mistakes and troubleshooting

  • Assuming pin numbers match port bit numbers—check the package pinout.
  • Forgetting common ground or the decoupling capacitor near VCC/GND.
  • Using a delay definition that does not match the configured CPU clock.
  • Leaving digital inputs floating; use a defined pull-up/down.
  • Driving motors/relays directly from a GPIO pin.
  • Changing fuses without recording original settings or preparing recovery access.
  • Assuming ADC result equals an exact voltage without accounting for reference, scaling and errors.
Memory aid: F-S-E = Flash (firmware), SRAM (scratchpad), EEPROM (settings). DDR–PORT–PIN = direction, drive/pull-up, read.
